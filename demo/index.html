Game feel for the web

teemo-tween

One-line tweens, sequences and juicy presets for browser games. Built on GSAP, typed, tested, and polite to players who prefer less motion.

npm i teemo-tween gsap
GitHub npm Presets Core API API reference

Presets

Small functions built only from the public API. Click a card to play it.

Core API

Every tween takes duration, ease, startDelay, endDelay, cycles, cycleMode and onComplete, and can be awaited.

MIT licensed. Animation powered by GSAP (a peer dependency under its own licence). API inspired by PrimeTween.
